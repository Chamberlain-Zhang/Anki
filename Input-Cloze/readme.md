在 Anki 的文本编辑框（即 `Text` 字段）中，你**不需要**直接写入 HTML 的 `<input>` 代码。

因为我们已经在卡片模板中写好了 JavaScript 脚本，它会自动扫描 `Text` 字段里的内容。你只需要使用 Anki 标准的**填空题语法（快捷键 `Ctrl + Shift + C`）**，脚本就会在前端自动把它们替换成精美的输入框。

具体操作方法和不同场景的写法如下：

---

### 1. 基础用法：单句中添加一个输入框

在 `Text` 字段中输入普通的句子，然后把你想要变成输入框的单词或短语用 `{{c1::...}}` 包裹起来。

* **你在 `Text` 字段输入的文本：**
```text
Anki {{c1::is}} a good tool.

```


* **实际呈现效果：** > Anki $\rightarrow$ `[ 填空 1 ]` $\rightarrow$ a good tool.

---

### 2. 核心功能：单句中添加“多个”输入框同时校验

如果你希望在一句话里留下好几个空，让它们**在同一张卡片上同时变成输入框**，只需要让它们的**序号完全相同**（全部使用 `c1`）。

* **你在 `Text` 字段输入的文本：**
```text
{{c1::Anki}} is a {{c1::good}} tool.

```


* **实际呈现效果：**
> `[ 填空 1 ]` $\rightarrow$ is a $\rightarrow$ `[ 填空 2 ]` $\rightarrow$ tool.


*(此时两个输入框会同时出现，你可以输入答案，背面会同时校验这两个空)*

---

### 3. 进阶用法：按步骤/分先后显示输入框

如果你希望这张卡片先考你词汇 A，下次再考你词汇 B，就需要使用**不同的序号**（`c1` 和 `c2`）。

* **你在 `Text` 字段输入的文本：**
```text
Anki {{c1::is}} a {{c2::good}} tool.

```


* **实际呈现效果：**
* **当抽学卡片 1 时：** `is` 的位置变成输入框，而 `good` 会直接显示为正常文本。
* **当抽学卡片 2 时：** `is` 直接显示为正常文本，而 `good` 的位置变成输入框。



---

### 💡 快捷键小贴士（极大提升制卡效率）

在电脑端 Anki 添加卡片时：

1. 用鼠标选中你想变成输入框的文本（例如选中单词 `is`）。
2. 同时按下键盘组合键：
* **`Ctrl + Shift + C`** (Windows)
* **`Cmd + Shift + C`** (Mac)


3. Anki 会自动帮你加上 `{{c1::is}}`。如果你接着选中第二个词并按下同样的快捷键，Anki 会自动递增变成 `{{c2::...}}`。
4. **如果你想做同时输入的多个框**：只需手动把 `{{c2::...}}` 里的数字 `2` 改成 `1`，让它们保持一致即可。
